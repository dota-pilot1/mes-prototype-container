# 테스트 로그인 자동화 구현 계획

## 개요

로그인 화면에서 역할별 버튼 5개를 누르면 해당 테스트 계정으로 즉시 로그인하고,
로그인 성공 후 role별 시작 페이지로 자동 이동하는 기능.

참고 프로젝트: `/Users/terecal/RestaurantBook`

---

## 동작 흐름

1. 로그인 화면에 **관리자 / 매니저 / 주방 / 직원 / 고객** 버튼 노출
2. 버튼 클릭 시 미리 정의된 이메일/비밀번호로 `authActions.login()` 실행
3. 로그인 성공 시 `getPostLoginPath()`로 이동 경로 계산
   - `next` 파라미터가 안전한 내부 경로이면 해당 경로로 이동
   - 없거나 `/login`, `/register`, `/unauthorized`, `/` 같은 경로면 role별 기본 홈으로 이동

## 관련 파일

| 파일 | 역할 |
|------|------|
| `TestLoginButtons.tsx` | 로그인 화면의 테스트 계정 버튼 UI와 클릭 시 자동 로그인 처리 |
| `testAccounts.ts` | 테스트 계정 목록, 기본 도메인/비밀번호, 노출 여부 설정 |
| `LoginForm.tsx` | 테스트 로그인 버튼을 로그인 폼 상단에 배치하고, 일반 로그인도 role별 redirect를 타도록 수정 |
| `roleRoutes.ts` | role별 기본 이동 경로와 로그인 후 이동 경로 계산 로직 |
| `env.example.txt` | 테스트 로그인 관련 환경변수 예시 추가 |

---

## 환경변수

`.env` 파일에 아래 항목 추가:

```env
NEXT_PUBLIC_ENABLE_TEST_LOGIN=true
NEXT_PUBLIC_TEST_ACCOUNT_DOMAIN=restaurantbook.local
NEXT_PUBLIC_TEST_ACCOUNT_PASSWORD=password123
```
