# 설비 예약 관리 계획

## 목표

설비별 사용 일정을 등록하고, 같은 설비의 시간 중복 예약을 방지한다.

## 연습 포인트

- 설비 master 모델링
- 시간 구간 overlap 검증
- 예약 상태 관리
- 캘린더/타임라인 UI

## 최소 기능

- 설비 등록
- 설비 예약 등록
- 예약 중복 검증
- 설비별 예약 목록 조회
- 예약 취소

## 백엔드 패키지

```text
equipment_reservation/
  domain/
  application/
  infrastructure/
  presentation/
```

## 구현 순서

1. 설비 엔티티 생성
2. 예약 엔티티 생성
3. 중복 예약 검증 로직 구현
4. 예약 CRUD API 생성
5. 프론트 예약 화면 생성

## 범위 제외

- 설비 점검 계획
- 반복 예약
- 교대조/작업자 배정
