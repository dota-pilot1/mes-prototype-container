# 생산 모니터링 대시보드 계획

## 목표

생산량, 불량률, 설비 가동률 등 생산 현황을 대시보드로 확인한다.

## 연습 포인트

- 여러 도메인 데이터 집계
- 대시보드 API 설계
- 카드/차트 UI
- 실시간처럼 보이는 폴링 구조

## 최소 기능

- 금일 생산량 표시
- 불량률 표시
- 설비 가동률 표시
- 진행 중 작업지시 표시
- 최근 이슈 표시

## 백엔드 패키지

```text
monitoring/
  application/
  presentation/
```

## 구현 순서

1. 생산실적 엔티티 초안 생성
2. 모니터링 집계 API 생성
3. 프론트 대시보드 카드 생성
4. 주기적 refetch 적용

## 범위 제외

- WebSocket 실시간 스트리밍
- 고급 차트
- 설비 PLC 연동
