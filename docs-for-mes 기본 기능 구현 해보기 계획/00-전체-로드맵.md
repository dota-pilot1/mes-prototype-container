# MES 기본 기능 구현 연습 로드맵

## 목적

실무 MES 프로젝트에 들어가기 전에 MES에서 자주 등장하는 도메인, DB 설계, API, 화면 흐름을 작은 단위로 연습한다.

## 구현 원칙

- 기능별로 작게 구현한다.
- 전체 DB를 처음부터 완성하지 않는다.
- 전체 ERD 초안은 잡되, 실제 테이블은 기능별 구현 시점에 확정한다.
- 백엔드는 DDD의 bounded context 느낌으로 나눈다.
- 프론트는 현재 보일러플레이트 구조를 유지하면서 기능별 화면을 하나씩 추가한다.
- 인증/권한/메뉴 관리는 기존 보일러플레이트를 활용한다.

## 권장 구현 순서

1. BOM 기반 자재 소요량 계산
2. 생산계획 등록 + 간트 차트
3. 설비 예약 관리
4. 작업지시 자동 스케줄링
5. 생산 모니터링 대시보드

## 백엔드 패키지 방향

```text
mes-prototype-server/src/main/java/com/cj/mesprototype/
  bom/
    domain/
    application/
    infrastructure/
    presentation/
  production_plan/
  equipment_reservation/
  work_order/
  monitoring/
```

## 공통 기준 모델 초안

- 품목: 생산품, 반제품, 원자재를 표현한다.
- BOM: 생산품 기준으로 필요한 자재와 소요량을 표현한다.
- 생산계획: 어떤 품목을 언제부터 언제까지 얼마만큼 생산할지 표현한다.
- 설비: 공정 또는 예약에 사용되는 생산 자원이다.
- 작업지시: 생산계획을 공정 단위로 쪼갠 실행 단위다.
- 실적: 생산량, 불량량, 가동시간 등 모니터링 원천 데이터다.

## 완료 기준

- 각 기능마다 DB, API, UI 최소 흐름이 동작한다.
- Swagger에서 API를 확인할 수 있다.
- 프론트 메뉴에서 기능 화면으로 이동할 수 있다.
- 기능별 README 또는 PLAN에 구현 범위와 남은 과제가 정리되어 있다.
