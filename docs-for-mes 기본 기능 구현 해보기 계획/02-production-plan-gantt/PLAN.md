# 생산계획 간트 차트 계획

## 목표

생산계획을 등록하고 기간별 생산 일정을 간트 차트 형태로 확인한다.

## 연습 포인트

- 기간 데이터 모델링
- 상태값 관리
- 리스트 + 타임라인 UI
- 품목과 생산계획 연결

## 최소 기능

- 생산계획 등록
- 생산계획 목록 조회
- 상태 변경
- 기간별 간트 차트 표시

## 백엔드 패키지

```text
production_plan/
  domain/
  application/
  infrastructure/
  presentation/
```

## 구현 순서

1. 생산계획 엔티티 생성
2. 생산계획 CRUD API 생성
3. 날짜 범위 조회 API 생성
4. 프론트 생산계획 화면 생성
5. 간트 차트 컴포넌트 구현

## 범위 제외

- 자동 스케줄링
- 공정별 작업지시 생성
- 휴일/교대조 캘린더
