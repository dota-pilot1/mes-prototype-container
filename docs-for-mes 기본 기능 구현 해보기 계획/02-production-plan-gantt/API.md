# 생산계획 API 초안

## 생산계획

- `GET /api/production-plans`
- `GET /api/production-plans/{id}`
- `POST /api/production-plans`
- `PUT /api/production-plans/{id}`
- `PATCH /api/production-plans/{id}/status`
- `DELETE /api/production-plans/{id}`
