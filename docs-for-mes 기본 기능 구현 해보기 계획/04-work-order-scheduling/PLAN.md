# 작업지시 자동 스케줄링 계획

## 목표

생산 지시 수량을 기준으로 공정별 작업 일정을 자동 생성한다.

## 연습 포인트

- 생산계획과 작업지시 연결
- 공정 라우팅 모델링
- 설비/시간 계산
- 간단한 스케줄링 알고리즘

## 최소 기능

- 공정 라우팅 등록
- 생산계획 기준 작업지시 생성
- 공정별 예상 시작/종료 시간 계산
- 작업지시 목록 조회

## 백엔드 패키지

```text
work_order/
  domain/
  application/
  infrastructure/
  presentation/
```

## 구현 순서

1. 공정/라우팅 모델 생성
2. 작업지시 엔티티 생성
3. 생산계획에서 작업지시 생성 API 구현
4. 단순 순차 스케줄링 로직 구현
5. 프론트 작업지시 화면 생성

## 범위 제외

- 최적화 알고리즘
- 설비 동시성 고급 배정
- 작업자 스킬 매칭
